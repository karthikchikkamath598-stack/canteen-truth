# 📊 Canteen Truth | Hypothesis Testing & Statistical Analysis App

**Canteen Truth** is an interactive, educational statistical web application built with **React** and **Vite**. It performs one-sample t-tests to verify real-world claims (e.g., college canteen portion sizes, product weights, battery life) with step-by-step mathematical breakdowns, visual t-distributions, simulation tools, error analysis (Type I & Type II), and downloadable printable reports.

---

## 🌟 Key Features

- **One-Sample t-Test Engine**: Dynamically calculates sample mean, sample standard deviation, degrees of freedom, t-statistic, critical value, and p-value.
- **Interactive Visualizations**: Interactive t-distribution curves and data distribution charts built with Recharts.
- **Step-by-Step Decision Timeline**: Understand *how* statistical decisions are made with clean step-by-step breakdowns.
- **Error Analysis**: Explore Type I ($\alpha$) and Type II ($\beta$) errors with interactive sensitivity adjustments.
- **Monte Carlo Simulations & Sample Size Comparer**: Test custom datasets and sample size variations dynamically.
- **Presentation & Report Export**: Export detailed printable reports for academic projects, lab submissions, or presentations.

## 🛠️ Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/karthikchikkamath598-stack/canteen-truth.git
   cd canteen-truth
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
